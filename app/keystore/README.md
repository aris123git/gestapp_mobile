# Keystore CI (debug / preview)

Keystore **stable** utilisé pour signer les APK debug/CI.

- Même signature → mise à jour possible **sans désinstaller**
- Mot de passe / alias : `android` / `maquiscaisse` (dev uniquement, pas pour Play Store prod)

Si un téléphone a déjà une version signée autrement, **une** désinstallation
sera encore nécessaire, puis exporter/importer la sauvegarde.
