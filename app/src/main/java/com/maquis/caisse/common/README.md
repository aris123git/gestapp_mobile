# common/

Composants et utilitaires **partagés** entre plusieurs écrans mais qui ne
sont ni des règles métier (→ `domain/`), ni des composants Compose
purement visuels (→ `ui/components/`).

Exemples attendus ici au fil des sprints : formatage de montants FCFA,
formatage de dates relatives ("il y a 3h"), extensions Kotlin communes.
